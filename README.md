***🚀 Crypto AI Prediction Dashboard***

A sleek Flask-based web app that predicts cryptocurrency prices and visualizes them with interactive charts.

*🌟 Preview*

*✨ Clean UI*
📊 Interactive charts
⚡ Real-time crypto data

*🧠 Features*
🔮 Future Price Prediction (custom days input)
📈 Interactive Graphs using Plotly


*💰 Supports:*
Bitcoin (BTC)
Ethereum (ETH)
Dogecoin (DOGE)


⚙️ Built with Flask backend


🎨 Responsive & modern UI


🛠️ Tech Stack


*Category	Tools Used*
Backend	Flask (Python)
Data Handling	Pandas, NumPy
API	yFinance
Visualization	Plotly.js
Frontend	HTML, CSS

⚙️ Installation & Setup


1️⃣ Clone the repo
git clone https://github.com/your-username/crypto-dashboard.git
cd crypto-dashboard

2️⃣ Create virtual environment
python -m venv venv
venv\Scripts\activate   # Windows

3️⃣ Install dependencies
pip install flask pandas yfinance plotly

4️⃣ Run the app
python app.py


🌐 Usage
Open browser
👉 http://127.0.0.1:5000
Select cryptocurrency
Enter number of days
Click Predict


📊 Boom — your prediction chart appears!
